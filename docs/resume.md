# ShramikSathi – AI-Powered Labour Rights Information Assistant

**Project Type:** Python | Generative AI | Retrieval-Augmented Generation (RAG)

**Tech Stack:** Python, FastAPI, Scikit-learn, TF-IDF, Groq LLM, Git, Docker, GitHub Actions, Render

### Key Contributions

- Developed **ShramikSathi**, an AI-powered Labour Rights Information Assistant using Python, FastAPI and Groq LLM to answer questions about Indian labour laws using information extracted from official government PDFs and FAQs.

- Built a **Retrieval-Augmented Generation (RAG) pipeline** involving PDF text extraction, overlapping text chunking, TF-IDF-based semantic retrieval, date-aware document ranking and source citations across 941 generated document chunks.

- Implemented production-focused features including response caching, prompt-injection protection, input validation, latency and token monitoring; achieved **20 passing automated tests** and integrated Ruff, Docker, GitHub Actions CI/CD and Render deployment.
